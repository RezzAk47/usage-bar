# Security

Usage Bar reads the local sign-in tokens of the supported AI coding tools (see [README](README.md#privacy) and
[docs/DETAILS.md](docs/DETAILS.md#credentials-and-safety)). If you find a way it could leak, write or log them, please email
rzk.karimi@gmail.com with steps to reproduce instead of opening a public issue. Do not include real tokens.

This is a one-person project: expect a reply within a few days, not hours. Only the latest version on `main` is supported.
